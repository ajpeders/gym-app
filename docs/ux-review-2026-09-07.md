# UX review — 2026-09-07

A screen-by-screen walkthrough of the web build on a phone-sized viewport,
driven in Playwright against a fresh account. Thirty-one pages. Each section
has the findings and Alex's verdict on them. Where Alex just said "agree",
every item in the section is accepted.

Screenshots live in `.playwright-mcp/NN-*.png` (git-ignored, local only).

The grouped list with a suggested build order is at the end.

---

## Per-page findings

### 1. Login (`/login`)
1. Landing screen should be two buttons, **Log in** / **Register**, not the login form.
2. Need a **forgotten-password** flow.
3. Enter-to-submit: fine.
4. Looks bad on desktop: the form stretches full width.
5. "Welcome back" belongs on the login form only, not the landing.

### 2. Register (`/register`)
- "Alex" placeholder reads as prefilled; two show-password eyes.

### 3. Onboarding (`/onboarding`)
- Top looks messy: WELCOME eyebrow + "Hi, Alex" + subtitle + "1 · Units" stack too many sizes with little spacing.
- Needs a better header block across the board (onboarding and Home share the pattern).

### 4. Home (`/`)
- **The grey band.** It is a fixed 160px backdrop in `Screen.tsx`, separate from `ScreenHeader`. Make the header a real container that owns its background and remove the floating band. That also fixes the stray band on Login, Splits and Spotter.
- Nutrition appears twice (quick-start tile and Track card). One goes.
- Start card and Quick start both answer "how do I begin".
- Zero-stat strip for new users: **keep it visible** (Alex's call, see History).
- Memory said the app was simplified to one tab plus More; this build has five tabs. Decide which before reworking the header.

### 5. Splits (`/workouts`)
1. Grey band cut-off: fix (header container work).
2. Swap emphasis: **Browse programs** primary, New day secondary.
3. Remove the empty-state text; the buttons already say it.
4. One name for the screen. Tab "Splits", eyebrow "Plan builder", route `/workouts`.

### 6. Library (`/exercises`)
1. Default order: recently used, then recently searched, then popular. Alphabetical last.
2. Drop the "EX" placeholder tile when there is no picture.
3. Web scrollbar inside the list: low priority, hide via web CSS.
4. Remove the "30 of 828" count.
5. Rename the tab Library → **Exercises**.

### 7. History (`/history`)
1. One stats vocabulary shared with Home: one component, same labels.
2. **Keep the zero stats visible.** Do not hide for new users. Applies to Home too.
3. Insights and Calculators move out of History into a More/tools area.
4. "History" ×3 (tab, title, section heading): one title, drop the section heading.
5. Catch up / backfill: keep, it's good.

### 8. Spotter (`/coach`)
1. Move behind More; surface as a tab only once AI is configured.
2. One name. Tab "Spotter", route `/coach`, onboarding "AI coach".
3. Grey band: fix (header container work).
4. Gate is fine, but put the AI config form **inline here** instead of bouncing to Settings.

### 9. Settings (`/settings`)
1. Don't probe `/api/ai/models` on load when no provider is configured (502 console error on open).
2. Ollama placeholder and the "Try http://192.168.0.40:11434" button leak the homelab IP. Neutral example.
3. Move AI config out of Settings to the Spotter gate. Settings = preferences + account.
4. Rename the "ChatGPT" chip → **OpenAI**.
5. Add **Delete account**. Onboarding's privacy line promises it.
6. Log out needs a confirm, on web and native.

### 10–12. Add-exercise picker and Active session
1. Search: word-based matching, not substring. "barbell bench" must find Bench Press. Reuse the import resolver.
2. Session rename: needed somewhere, low priority. It's just "the session".
3. Remove the top "Add exercise" button; keep "Add another exercise" at the bottom.
4. Quick-add set buttons: toggle is on but nothing shows. See Finish, item 3.
5. **Log set** is the only mint button during a workout. Add exercise goes secondary.
6. Header cleanup (back arrow + red trash); **confirm on Discard**.
7. Delete-set cross is too small and too easy to hit.
8. **Log-set inputs and buttons much bigger**, gym-usable between sets. Add a **voice button** to log set(s) by speech.

### 13–14. Finish and Session detail (`/session/:id`)
1. Add a finish summary (duration, sets, PRs, Done) before landing on History.
2. **Bug:** stale "Session in progress" banner right after finishing. `finish()` clears the active id last, after the server call. Clear it before navigating.
3. Quick-add buttons should appear after the first set of the session, not only when prior history exists. `ActiveExerciseCard.tsx` gates on `last`.
4. Session detail is good; realign the Edit/Export header icons with the title.
5. Rename the session via Edit on the detail page.

### 15–16. Programs (`/presets`) and Split detail (`/split/:id`)
- Overall verdict: **too cluttered.**
- Programs: collapse each card, tap to expand, one Use button visible at a time. Drop or wrap the truncated lift previews. Missing back arrow on web.
- Split page: "Edit" header text clipped at the right edge. "Up next" marker plus a Start on every row duplicate each other; one Start on the rotation card. Confirm on Delete split. Four sections (rotation, rules, workouts, manage) for one plan is too many.
- **Bug, found by accident:** tapping a workout row on the split page **starts a session immediately**. It should open the workout; Start stays a button.

### 17. Edit workout (`/workout/:id`)
1. Weight and Time placeholders wrongly show "8-12". Use weight-shaped and time-shaped hints.
2. PR line in the exercise header: keep.
3. Reorder arrows: bigger tap targets. Drag later.
4. Rest default (e.g. 90s) instead of "-".
5. Missing back arrow (web).
6. Density is fine here.

### 18–19. Import and Review import (`/workout-import`)
- Remove the "Don't have one? Browse programs" box; Splits already leads with programs.
- Move the history-CSV box to History next to "Add past session", so the import page does one thing.
- Prefill the plan name from the paste or file name.
- Collapse exercise rows; tap to reveal Edit / Swap / Remove. Two days currently show eighteen buttons.
- "close match" must look distinct from a clean match, and low-confidence matches flagged. "Cable Kickback Thing" → Cable Tricep Kickback was shown with full confidence.
- "Re-importing a plan you already have will leave you with two of it" is good copy.

### 20. Nutrition (`/nutrition`)
1. One input box (food search, description, or "chicken 300 cal") instead of three stacked methods.
2. Hide the AI "describe it" box when no provider is configured, or say why it's off.
3. Common-food tap needs a quantity control. It assumes 100g.
4. "Set targets" as a link on the Today card, not a sentence.
5. Missing back arrow (web).
6. Keep calories + protein only.

### 21. Profile (`/profile`)
1. One stats component with one rule. Home, History and Profile currently disagree (Profile counts an unfinished session).
2. Hide the "Today" coach note when AI is off.
3. Group goals / equipment / preferences / notes under a collapsed "Coach context" section, hidden when AI is off.
4. Weight field should show the latest weigh-in and link to log one, not be a separate field.
5. Calorie and protein targets first, labeled as nutrition targets.
6. Back arrow; drop the double title ("Profile" header + "About you").

### 22–24. Progress and Log weigh-in (`/progress`)
1. Not reachable from any tab. Link from Home's Track section or More.
2. Weight card should draw the trend once 2+ entries exist. The API already serves it.
3. Weigh-in is the primary action, photos secondary.
4. Weigh-in sheet is good; placeholder should be the last weigh-in.
5. Weigh-in is the single source of weight. Profile and Nutrition read from it.

### 25. Insights (`/insights`)
1. "Next time" card → Home (or top of Splits). Insights is eight sections, too many.
2. **Check:** headline says "2 hard sets" but the Chest bar says "Nothing logged" after one bench set.
3. Gaps: with no data say "log a week first", don't list all eleven muscles.
4. "How today feels" is an input; move it to session start.
5. Milestones: show the next one or two, not all ten.
6. Weekly tonnage: hide until 2+ weeks.

### 26. Calculators (`/calculators`)
1. Tidiest page in the app. Keep the structure.
2. Live-update results as you type; drop the three buttons.
3. Bar-weight choice (20 / 15 / 10).
4. Plate calculator inline in the active session next to the weight field.

### 27–28. Log by text (`/log-chat`)
1. Deterministic local parser for "bench 3x8 @60" shapes first; AI only as fallback. Voice and text logging must work without an API key.
2. Mic button moves to the active session (or the session opens this from a mic).
3. Replace the chat transcript with an input plus a review list.

### 29. Exercise detail (`/exercise/:id`)
1. Photo override works; keep.
2. Clean catalog instructions: strip preamble paragraphs and "Notes (Instructions):" headings.
3. Plain-name map for muscles, no Latin.
4. Chips: make them plain labels unless they filter.
5. Show last sets + PR above the instructions once logged.
6. "Add to active session" sticky at the bottom.

### 30. Catch up (`/catch-up`)
1. **Bug:** rotation splits back-fill "Push" onto every past day, including before the split existed. Thirteen amber warnings for a plan adopted an hour ago. Window starts at split creation; rotations don't guess a day.
2. Neutral styling for missed days, not amber warnings.
3. "Paste several days" needs the no-AI parser too.
4. Back arrow.

### 31. Admin (`/admin`, as a non-admin)
1. Headline "Something went wrong" is wrong. Nothing went wrong. "Admin only" plus the existing second line is enough.
2. Don't fire four requests the page knows will be refused.
3. URL-only for non-admins. Low priority.

## Grouped by theme, in suggested build order

Each group is one focused branch. Order is by value to someone standing in a
gym, then by how much each fix unblocks the next.

### 1. Bugs (small, do first)
- Stale "Session in progress" banner after finishing (Finish 2).
- Tapping a workout row on the split page starts a session (Split page).
- Catch up back-fills the next rotation day onto every past day (Catch up 1).
- Insights headline counts hard sets that the muscle bars don't (Insights 2).
- Settings probes AI models on load with no provider → 502 (Settings 1).
- Admin fires four refused requests and reports "Something went wrong" (Admin).

### 2. Shell: header, names, navigation
- Replace the fixed grey band with a header container that owns its background (Home). Fixes Login, Splits, Spotter, Onboarding in one go.
- Back arrow on every stacked page on web (Programs, Edit workout, Nutrition, Profile, Catch up).
- One name per screen: Splits, Exercises, Spotter. Drop eyebrows that disagree with the tab. Drop double titles (History ×3, Profile/About you).
- Landing = two buttons (Log in / Register). "Welcome back" only on the login form. Fix the desktop layout.
- A **More** area for Insights, Calculators, Progress, and Spotter-until-configured. Progress is currently unreachable.

### 3. The logging loop (highest value)
- Bigger log-set inputs and buttons. Log set is the only primary button.
- Voice button on the active session, built on a **deterministic local parser** for "bench 3x8 @60" shapes. AI is fallback only. Same parser serves Log by text and Catch up's paste.
- Word-based exercise search, reusing the import resolver.
- Quick-add buttons from the first set of the session.
- Confirm on Discard; bigger delete-set target; remove the duplicate top Add exercise.
- Finish summary screen (duration, sets, PRs, Done).
- Plate calculator inline next to the weight field.
- Rename via Edit on session detail. Realign the detail header icons.

### 4. AI gating and Settings
- AI config moves to the Spotter gate; Settings = preferences + account.
- Hide every AI affordance when no provider: Nutrition "describe it", Profile Today note and coach-context fields, Catch up paste.
- "OpenAI" everywhere, never "ChatGPT". Neutral Ollama example, no homelab IP.

### 5. One source of truth
- One stats component with one rule and one vocabulary on Home, History, Profile. Zeros stay visible.
- Weigh-in is the single source of weight; Profile and Nutrition read from it. Progress draws the trend.
- Nutrition once on Home. "Next time" card moves to Home.

### 6. Declutter
- Programs: collapsible cards, one Use visible. Split page: one Start, three sections not four, confirm on delete, unclipped Edit.
- Import: one job per page (history CSV → History), collapsed exercise rows, prefilled name, visible low-confidence matches.
- Nutrition: one input, quantity control, targets link.
- Insights: gaps copy, next 1–2 milestones, tonnage hidden until 2 weeks, readiness moved to session start.
- Calculators: live results, no buttons, bar-weight choice.
- Library: recency/popularity order, no placeholder tile, no count.
- Edit workout: real placeholders, 90s rest default, bigger reorder arrows.

### 7. Account
- Forgotten password.
- Delete account (promised in onboarding).
- Confirm on Log out.

### 8. Catalog data
- Strip source preamble and "Notes (Instructions):" from instructions.
- Plain-name muscle map.
- Exercise detail: last sets + PR above instructions, sticky Add to session.
